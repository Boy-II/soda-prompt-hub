第一次使用？查看 5 步指南
01先写想法或选 OC在创作台新建项目，也可以先从角色库导入 OC Manager JSON。
02找提示词和参考图去提示词库或智能检索，挑选服装、动作、构图、灯光和画风。
03整理两种 Prompt同一份创作意图分别检查 Anima 标签和 Krea 2 自然语言版本。
04需要时交给 Windows 出图Windows 开机并运行 Worker 后再发送；离线时可以继续整理本地内容。
05精选、打标并交付数据集结果图回到 Mac 后人工筛选，检查 WD14 草稿，最后冻结并导出版本。
